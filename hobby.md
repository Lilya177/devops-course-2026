# Мой пет-проект
Идея: Телеграм-бот для мониторинга криптовалют в реальном времени. Бот каждые 30 секунд проверяет цену Bitcoin на бирже Binance и отправляет экстренные уведомления, если цена выходит за заданные пределы (верхний/нижний порог).
Стек: Python
Цель: Освоить асинхронное программирование на практике через создание Telegram-бота, который в реальном времени отслеживает курсы криптовалют, параллельно обрабатывая команды пользователей и отправляя уведомления при изменении цены.
